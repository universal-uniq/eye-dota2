# 👁 Eye Dota 2

Мини-портал по Dota 2.

🔗 **Live:** https://universal-uniq.github.io/eye-dota2/

## Вкладки

| Вкладка | Описание |
|---|---|
| **Серверы** | Live-статус CM-серверов Valve |
| **Мета** | Топ героев по пикам/винрейту |
| **Сборки** | Предметы по герою по этапам игры |
| **Герои** | Поиск + Hero-page с матчапами и билдом |
| **Патч** | Текущий патч + список |
| **Стата** | Матчи за 24ч, топ пиков/банов |
| **Топ-100** | Immortal-игроки |
| **🎯 Рекомендации** | Анализ твоих 50 матчей |
| **⚔️ Пик** | Идеальные пики и баны против врагов |
| **Лиги** | Список лиг |
| **Про** | Свежие про-матчи |
| **Профиль** | Игрок с графиками |
| **🔗 Сайты** | Полезные ресурсы |
| **Матч** | Полная таблица игроков + графики + Рошан |

## Матч — что внутри

- **Таблица игроков**: уровень, net worth, GPM/XPM, LH/DN, hero/tower dmg, healing, 6+3+1 слотов предметов, порядок прокачки скиллов, руны, стаки, варды, buyback
- **Графики**: net worth advantage, XP advantage, net worth по игрокам
- **События**: Рошаны, первая кровь

## Настройки (⚙️ в топбаре)

- **5 цветов** — оранжевый, красный, синий, зелёный, фиолетовый
- **Тема** — тёмная/светлая/авто
- **Размер шрифта** — S/M/L
- **Компактный режим**

Всё сохраняется в localStorage.
