# 👁 Eye Dota 2

Мини-портал по Dota 2: статус серверов, мета, сборки, лиги, про-сцена,
профиль игрока, сравнение игроков и подборка полезных сайтов.

🔗 **Live:** https://universal-uniq.github.io/eye-dota2/

## Вкладки

| Вкладка | Что показывает |
|---|---|
| **Серверы** | Live-статус CM-серверов Valve (гибрид: Worker → прокси) |
| **Мета** | Топ героев по популярности / винрейту / contested |
| **Сборки** | Предметы по герою — компактные карточки, иконки грузятся через 3 источника |
| **Лиги** | Список лиг из OpenDota |
| **Про-сцена** | Свежие про-матчи + топ команд |
| **Профиль** | Игрок: аватар, ранг, матчи, герои, графики |
| **Сравнить** | Side-by-side двух игроков |
| **🔗 Другие сайты** | Полезные ресурсы по Dota 2 |

## Как грузятся иконки предметов

Для каждого предмета формируется **список из 3 URL**:

1. `item.img` из ответа OpenDota (`/api/constants/items`)
2. `cdn.../items/<slug>_lg.png` — старый надёжный путь Valve
3. `cdn.../items/dota_react/<slug>.png` — новый путь

Если первый URL 404 — `onerror` вызывает `__tryNextImg` и пробует следующий.
Если все три упали — показывается заглушка `❔`.

Это **гарантирует**, что иконка появится, если хотя бы один путь рабочий.
