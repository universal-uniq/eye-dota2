# 👁 Eye Dota 2

Мини-портал по Dota 2.

🔗 **Live:** https://universal-uniq.github.io/eye-dota2/

## Что внутри

| Вкладка | Функционал |
|---|---|
| **Серверы** | Live-статус CM-серверов Valve по регионам |
| **Мета** | Топ героев по пикам/винрейту |
| **Сборки** | Предметы по герою на разных этапах игры |
| **Герои** | Поиск героев + Hero-page с матчапами и билдом |
| **Патч** | Текущий патч + последние 20 + ссылки на нотсы |
| **Стата** | Матчи за 24ч, длительность, топ пиков и банов |
| **Топ-100** | Immortal-игроки |
| **Лиги** | Список лиг из OpenDota |
| **Про** | Свежие про-матчи + команды |
| **Профиль** | Игрок: аватар, ранг, матчи, герои, графики |
| **Сравнить** | Side-by-side двух игроков |
| **🔗 Сайты** | Полезные ресурсы |

## Фичи

- 🌐 **RU / EN** — переключатель языка (кнопка `RU` справа вверху)
- 🌗 **Тёмная / светлая тема** (кнопка 🌙)
- 🔀 SPA-роутинг на хэшах
- 📊 Chart.js — GPM/XPM, K/D/A, длительность матчей
- 🎯 Hero-page: `#/hero/{id}` — полная статистика
- 🔗 Прямые ссылки: `#/hero/1`, `#/player/88141661`, `#/match/7123456789`

## Источники картинок

| Что | URL |
|---|---|
| Герои | `cdn.cloudflare.steamstatic.com/.../heroes/<slug>.png` |
| Предметы | `item.img` из OpenDota (fallback: `dota_react` → `_lg`) |
| Ранги | `www.opendota.com/assets/images/dota2/rank_icons/rank_icon_<N>.png` |
